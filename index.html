BAGIAN FILE - index.html : website untuk GitHub Pages. - Code.gs : backend Google Apps Script untuk menyimpan foto ke Google Drive. A. SIAPKAN GOOGLE DRIVE 1. Buat folder Google Drive, misalnya "FOTO STAFF". 2. Buka folder itu. URL berbentuk: https://drive.google.com/drive/folders/ID_FOLDER Salin bagian ID_FOLDER. 3. Buka https://script.google.com/ lalu buat project baru. 4. Hapus kode contoh, tempel seluruh isi Code.gs. 5. Ganti 1ek2alB19B2C6JEfBY8De6Avxnhsp4UyK dengan ID folder yang disalin. 6. Simpan project. B. DEPLOY GOOGLE APPS SCRIPT 1. Klik Deploy > New deployment. 2. Pilih jenis Web app. 3. Execute as: Me. 4. Who has access: Anyone. Penting: setting ini memungkinkan staff mengirim tanpa login Google. Karena itu, gunakan folder khusus dan jangan simpan dokumen sensitif di folder tersebut. 5. Klik Deploy dan selesaikan otorisasi Google. 6. Salin URL Web app yang berakhiran /exec. C. HUBUNGKAN WEBSITE 1. Buka index.html. 2. Cari: const SCRIPT_URL = "https://script.google.com/macros/s/AKfycbzDe6iwL7fsxpuFO0JZ3YUmQ9XFHOwnBf7nAhcfXlZCUsyJpimmaxNHOUDktmcaqCzIKQ/exec"; 3. Ganti dengan URL Web app /exec, contoh: const SCRIPT_URL = "https://script.google.com/macros/s/...../exec"; 4. Simpan. D. PUBLIKASIKAN DI GITHUB PAGES 1. Buat repository GitHub baru, misalnya staff-photo-upload. 2. Upload index.html ke root repository. 3. Buka Settings > Pages. 4. Pada Build and deployment, pilih Deploy from a branch. 5. Pilih branch main dan folder /(root), lalu Save. 6. Buka URL GitHub Pages yang diberikan GitHub. Gunakan HTTPS. 7. Tes di HP. Izinkan akses kamera saat browser meminta. CATATAN PENTING - Pilihan section yang tersedia saat ini FRONT dan BACK. - Nama file otomatis menjadi NAMA-SECTION.JPG. Contoh: Desti + Front = DESTI-FRONT.JPG. - Nama dengan spasi akan menggunakan tanda hubung, contoh "Desti Putri" menjadi DESTI-PUTRI-FRONT.JPG. - Google Drive mungkin menyimpan file JPG meskipun foto dibuat dari kamera dalam format JPEG; keduanya kompatibel. - Jika mengubah Code.gs setelah deploy, buka Deploy > Manage deployments > Edit (ikon pensil) > pilih New version > Deploy. - Uji pertama menggunakan satu foto percobaan.
